## ⚡ Live Visual Tour & Highlights

- **Live Theme Voltage Detonator:** Real-time CSS Custom Property morphing (`--theme-primary`, `--theme-secondary`, `--theme-hot`) across 6 signature SKUs accompanied by screen-shake micro-animations.
- **Interactive 2D Canvas Liquid Splash Physics:** Outlined neon droplet burst engine with custom velocity and gravity trajectories that detonates wherever users click or tap.
- **"Lab Riot" Custom Potion Blender:** Interactive SVG hydraulic vessel with dynamic wave fill levels that mix colors live as up to 5 raw shots are loaded, accompanied by an FDA-style Nutrition Facts Receipt that recalculates live calories, vitamin C %, Scoville heat, and price.
- **The Flavor Vault & 6-Pack Crate Builder:** Filterable menu with acidity, heat kick, and voltage meters, featuring a dynamic 6-slot progress bar that unlocks an automatic **15% Syndicate Bundle Discount** in the slide-out cart drawer.
- **Live High-Voltage Telemetry Hazard Bar:** Animated hazard chevrons, jittering facility voltage readouts (14,200V+), countdown timers, and simulated real-time syndicate dispatch toasts.
- **Wholesale Customs Manifest:** Hazmat-styled shipping manifest clipboard with an explosive **"APPROVED // JUICE INBOUND"** rubber-stamp slam animation on form transmission.
- **Choreographed Mobile Maximalism:** Custom bottom thumb-zone arcade dock and touch-optimized snap cards preventing unreadable layout shrinking on smaller viewports.

## 🚀 Quickstart & Local Execution

Get the project running locally in 2 simple commands:

```bash
# 1. Clone the repository
git clone https://github.com/Daniyalzahid9/pulp-riot.git
cd pulp-riot

# 2. Start the local server
npm start
```

Open your browser at **`http://localhost:4321`** (or access via your local Wi-Fi network on mobile).

## ⚙️ Technical Highlights

- **Compositor-Only Animations:** All layout shifts and drawer transitions utilize GPU-accelerated `transform` and `opacity` properties.
- **Native Web Standards:** Uses modern CSS Custom Properties, SVG clip paths, `<dialog>` / `<aside>` drawer patterns, and responsive CSS Grid with `clamp()` fluid type scaling.
- **Scoped Reduced Motion:** Respects user accessibility preferences (`@media (prefers-reduced-motion: reduce)`) without jarring abrupt halts.
